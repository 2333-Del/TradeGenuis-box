# 多周期共振筛选重设计方案

> 2026-09-07 · 基于 9/7 全市场扫描数据（5209 只、达标 0）的复盘

## 一、结论先行

达标 0 **不是市场没有机会，而是筛选逻辑存在三个结构性问题**：

1. 双门槛串联（评分≥85 AND 三周期共振）把概率压到 0：评分≥85 在 5193 只里只剩 **13 只**（0.25%），这 13 只里 30m 突破 0 只、1h 突破 1 只、1d 突破 0 只，交集必然为空。
2. 「共振」的实现语义是「三个周期在各自最近 3 根K内**同时首次点火**」——30m 的 3 根是 1.5 小时，1d 的 3 根是 3 天，同一价格事件在两个时间尺度上的"新鲜度"要求完全错位。离线模拟证明：即使把窗口放宽到 34 根，13 只里三周期交集仍是 0。
3. 两道门槛在时间轴上**互斥**：四条件奖励「箱内试盘、收盘未破上沿」（试盘≥3 次的定义就是未突破），共振要求「已突破」。今天真正在多周期突破的股票（当日涨幅≥5% 有 341 只），大多因试盘条件反而拿不到 85 分，根本进不了共振评估——`apply_resonance` 只对评分≥85 的股票拉分钟线。

### 数据证据（9/7 14:33 扫描）

| 指标 | 数值 |
|---|---|
| 有效评分 | 5193 / 5209 |
| 评分≥85（进入共振评估） | 13 只 |
| 这 13 只中 1d 突破（近 3 根） | 0 只 |
| 这 13 只中 1d 状态（近 30 根诊断） | 全部未突破：距箱顶 -0.9% ~ -28%，多为箱内试盘股 |
| 放宽 RECENT=5/8/13/21/34 后三周期交集 | 仍为 0 |
| 当日涨幅≥3% / ≥5% / ≥7% | 726 / 341 / 178 只（点火候选真实存在） |

## 二、重设计：状态分层共振，替代「同时首次点火」

### 2.1 每个周期评一个状态（而非二值 ok）

对 30m / 1h / 1d 各自计算：

| 状态 | 定义 | 含义 |
|---|---|---|
| `BREAK` | 近 `RECENT_p` 根内首次收盘上穿箱顶×1.005 且此后收盘未跌回箱顶下（现口径），**或**现价站稳箱顶上方（close > box_high×1.002 且近 3 根低点不破箱顶） | 已突破 |
| `NEAR` | 现价距箱顶 ≥ -3% 且箱内位置 ≥ 85%（即贴近上沿蓄势） | 临界 |
| `INSIDE` | 箱体上半区但未到临界 | 蓄势 |
| `BELOW` | 箱体下半区 | 观望 |

窗口按周期自身节奏设定（关键改动：**不再共用 RECENT=3**）：

| 周期 | RECENT | 对应时间跨度 | 说明 |
|---|---|---|---|
| 1d | 10 根 | 约 2 周 | 日线突破后允许回踩确认 |
| 1h | 8 根 | 约 2 个交易日 | 小时级近期点火 |
| 30m | 6 根 | 当日 | 当日盘中触发 |

### 2.2 共振分级

```
强共振 = 1d∈{BREAK}          且 1h∈{BREAK, NEAR}  且 30m∈{BREAK, NEAR}
准共振 = 1d∈{BREAK, NEAR}    且 (30m∈{BREAK} 或 1h∈{BREAK})      # 日线临界 + 小周期点火
临界池 = 1d∈{NEAR}           （不推送，仅看板展示，次日跟踪）
```

含义：「日线定方向，小时定确认，30 分钟定买点」——这正是多周期共振战法的标准分层语义，替代了原来"三只秒表必须同时归零"的不可实现定义。

9/7 数据回测：13 只高分股中，**深城交**（1d NEAR + 1h BREAK）按新定义命中「准共振」。佳发教育（1h/30m 双 BREAK、1d 距箱顶 -5.5%）为典型「临界池」标的。分层后信号开始出现。

### 2.3 漏斗反转：共振为主筛，四条件降为质量分

现在的顺序是「四条件(0.25%) → 共振」，应改为：

```
活跃池粗筛（当日换手≥2% 或涨幅≥2% 或量比≥1.2，约 500-700 只；自选池保送）
   ↓
拉 30m 分钟线 → 三周期状态计算（每只 1 次 mkline 请求，8 线程约 2-3 分钟）
   ↓
共振分级（强 / 准 / 临界 / 无）                     ← 主筛选器
   ↓
四条件评分作为同级别内的排序质量分                 ← 次级排序
   ↓
推送：强共振全部推送；准共振中评分≥70 的推送
```

- 评分不再"一票否决"：一只评分 65 但三周期强共振的股票，比评分 87 但日线还在箱体中部的股票更符合你的初衷。
- `qualify()` 保留双字段输出（`score` + `resonance_level`），看板按共振级分区展示。

## 三、ETF 纳入

当前 universe（`UNIVERSE_FS`）只拉沪深 A 股，场内 ETF 完全不在扫描范围。`fund.py` 是"基金重仓股"信号，不是 ETF 行情扫描，两者不要混淆。

### 3.1 行情可行性

- **列表**：东财 clist 场内基金板块（候选 fs 参数 `m:1+t:12,m:0+t:12`，实现时以东财「ETF 行情」排行页实际请求抓包为准），按代码前缀过滤 `51/58/56/159/15` 确认是场内 ETF；日缓存进 `data/etf_universe.json`。
- **分钟线**：腾讯 `mkline` 对 ETF 同样可用（`sh510300` 等），`fetch_stock_timeframes` 无需大改，`tx_symbol` 已正确处理 5 开头代码。

### 3.2 ETF 评分口径（独立于 A 股四条件）

ETF 无概念板块、无股东户数、主力资金接口通常无数据 → 走「纯量价」口径，总分 100：

| 条件 | 分值 |
|---|---|
| 多周期共振（强 50 / 准 30 / 临界 15 / 无 0） | 50 |
| 倍量≥3 日（量 ≥ 前 5 日均量 1.8 倍） | 25 |
| 箱体上沿试盘 ≥3 次 | 25 |

达标线同样定 85（实际只有"强共振 + 量能配合"能到），看板单列 ETF 区。

## 六、风险与注意

1. **强共振每日 0-5 只是正确密度**——真信号本来就稀有。如果连续多日为 0，先查数据层（`resonance_status` 里"数据不可用"占比），不要先放松阈值。
2. 30m 共振判定依赖**已收盘的 30 分钟K**，11:30 / 15:00 两个自动扫描点正好各落在上午收盘后与全天收盘后，调度不用动；盘中其他时点手动扫描只会用到上一个已收盘槽位，行为一致。
3. NEAR（临界池）是"预备队"不是买点，它的价值在**次日跟踪**——今天贴着箱顶的股票，明天放量上穿才升级为准/强共振。看板保留临界池就是为了这个"昨天临界、今天点火"的连续性。
4. ETF 资金流/概念接口大概率无数据，不要在 ETF 上硬套 A 股四条件，否则会复刻这次的"达标 0"。
5. 东财 f10 量比字段本次实测全 0（可能是拉取时点或参数问题），活跃池条件以换手+涨幅为主、量比为辅，并排查 `_universe_em` 的 fields 参数。
